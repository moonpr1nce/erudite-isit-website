# erudite-isit-website

Сайт Международной школы инновационных технологий «Эрудит» (Erudite ISIT), Бишкек.

Статическая страница без сборки: вся вёрстка, стили и скрипты — в `index.html`, изображения и логотип — в `assets/`.

## Локальный запуск

```bash
python3 -m http.server 4321
```

Затем откройте http://localhost:4321.

## Что внутри

- Перерисованный логотип в SVG — `assets/logo.svg`
- Интерактивные ступени обучения (0, 1–4, 5–9, 10–11)
- Форма записи на пробный день: собирает заявку и открывает WhatsApp школы с готовым сообщением
- Карта, частые вопросы, контакты

Данные о школе взяты из открытых источников: официальный сайт школы, 2ГИС, Kaktus.media.
